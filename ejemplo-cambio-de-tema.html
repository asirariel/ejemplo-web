Cambio de tema con JavaScript

Ejemplo del Tema 3: un botón activa o desactiva una segunda hoja de estilos.

Pruébalo

El botón alterna entre el modo claro y el oscuro. La elección se guarda en el navegador y se mantiene al cambiar de página.

Cómo funciona

Cada página enlaza la hoja clara y, desactivada, la hoja oscura:

<link rel="stylesheet" href="css/estilos.css">
        <link id="tema-oscuro" rel="stylesheet" href="css/estilos-oscuro.css" disabled>

El script solo cambia la propiedad disabled del segundo enlace. Como la hoja oscura redefine las variables de color, toda la página cambia a la vez:

const enlaceOscuro = document.getElementById("tema-oscuro");
        enlaceOscuro.disabled = !enlaceOscuro.disabled;

El código completo, con la memoria de la elección, está en js/tema.js.
