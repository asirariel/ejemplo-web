1. Estructura del documento

<!DOCTYPE html>
Declara el documento como HTML moderno para que el navegador use el modo estándar.
<html lang="es">
Elemento raíz. lang declara el idioma principal para accesibilidad, buscadores y pronunciación. En páginas escritas en inglés se usa en.
<head> / <body>
head contiene metadatos, título, CSS y scripts; body contiene el contenido presentado al usuario.
<meta charset="UTF-8">
Permite mostrar correctamente tildes, eñes y otros caracteres.
<meta name="viewport" content="width=device-width, initial-scale=1.0">
Adapta el ancho de la página a la pantalla del dispositivo. El nombre correcto es viewport.
<meta name="author">
Indica quién creó el documento.
<title>
Define el título de la pestaña y el nombre usado por marcadores y buscadores.
<link rel="stylesheet" href="...">
Vincula una hoja CSS externa. href es la ruta y rel declara la relación del archivo.
<script src="...">
Carga JavaScript externo. src contiene su ruta; el código de esta carpeta usa funciones de la calculadora.

2. Estructura semántica y navegación

<header>, <main>, <footer>
Cabecera, contenido principal único de la página y pie con información final.
<nav>
Contiene enlaces de navegación. aria-label ofrece un nombre accesible al menú; aria-current="page" marca el enlace de la página actual.
<section>
Agrupa contenido relacionado, normalmente con un encabezado.
<div>
Contenedor genérico de bloque, útil para agrupar contenido y aplicar estilos cuando no hay un elemento semántico más adecuado.
<dl>, <dt>, <dd>
Lista de definiciones, término que se describe y descripción del término.
<h1>–<h6>
Encabezados ordenados por nivel; h1 es el título principal y los niveles siguientes estructuran subsecciones.
<p>
Párrafo de texto.
<details> / <summary>
Crean un panel desplegable nativo; summary es la parte visible que se pulsa.
<hr> / <br>
hr separa temáticamente el contenido; br inserta un salto de línea dentro de un texto.

3. Texto, listas, enlaces e imágenes

<strong> / <em>
Marcan importancia y énfasis. El navegador suele mostrarlos en negrita y cursiva.
<span>
Contenedor genérico en línea para seleccionar o estilizar parte del texto.
<pre> / <code>
pre conserva espacios y saltos; code representa código informático en línea.
<del>, <sub>, <sup>
Texto eliminado o tachado, subíndice y superíndice.
<ul> / <ol> / <li>
Lista sin orden, lista numerada y elemento de una lista.
<a href="...">
Enlace. href indica destino; puede apuntar a otra página, una dirección externa, un correo con mailto: o un identificador de la misma página. target="_blank" abre otra pestaña.
<img src="..." alt="...">
Inserta una imagen; src es el archivo y alt una descripción alternativa accesible.

4. Tablas y formularios

<table>, <caption>
Tabla de datos y su título descriptivo.
<thead> / <tbody>
Agrupan respectivamente las filas de encabezado y las filas de datos.
<tr>, <th>, <td>
Fila, celda de encabezado y celda de datos. rowspan extiende una celda por varias filas y colspan por varias columnas.
<form action="..." method="...">
Contenedor de controles para enviar datos. action indica el destino y method el método de envío; # no configura un servicio real.
<fieldset> / <legend>
Agrupan controles relacionados y proporcionan el título del grupo.
<label for="id">
Etiqueta descriptiva asociada al control cuyo id coincide con for.
<input>
Control de entrada. En estas páginas aparecen type="text", email, submit y reset; id identifica el control, name es la clave enviada, required lo hace obligatorio, value fija su valor, y disabled lo desactiva.
<textarea>
Campo de texto de varias líneas; rows y cols sugieren sus dimensiones.
<button>
Botón interactivo. En la calculadora sus atributos onclick llaman a funciones JavaScript al pulsarlo.

5. Cómo se escribe CSS

Una regla se compone de un selector y declaraciones entre llaves: selector { propiedad: valor; }. El selector elige los elementos; cada propiedad cambia un aspecto. Un selector de etiqueta como p alcanza todos los párrafos; .clase selecciona elementos con esa clase; #id selecciona el elemento con ese identificador; las comas agrupan selectores; los espacios indican descendientes; :hover actúa al pasar el puntero; [type="email"] selecciona por atributo; * selecciona todos los elementos.

Propiedades usadas en las hojas CSS del proyecto

font-family, font-size, font-style, font-weight
Familia tipográfica y alternativas, tamaño, variante como cursiva y grosor como negrita.
color, background, background-color, background-image
Color del texto; fondo abreviado; color de fondo; e imagen de fondo.
background-repeat, background-position, background-size
Controlan repetición, colocación y tamaño de la imagen de fondo.
text-align, text-decoration, line-height
Alineación del texto, decoración como subrayado y separación vertical entre líneas.
margin, margin-top, margin-right, margin-bottom, margin-left
Espacio exterior del elemento; las variantes fijan cada lado.
padding, padding-left
Espacio interior entre contenido y borde; puede definirse para todos los lados o para la izquierda.
width, max-width, height
Ancho, ancho máximo y alto del elemento. height aparece como concepto de dimensión y puede usarse aunque no tenga regla en las hojas actuales.
display, list-style, gap
Modo de disposición (por ejemplo, bloque, en línea o flex), marcador de listas y separación entre elementos flexibles.
border, border-width, border-top, border-left, border-radius
Borde completo, grosor, borde superior o izquierdo y redondeo de esquinas.
border-collapse, border-spacing
Determinan si los bordes de tabla se fusionan y qué espacio hay entre celdas.
box-sizing
Define cómo se calcula el ancho/alto; border-box incluye relleno y borde en el ancho declarado.
box-shadow
Añade una sombra exterior para dar profundidad.
cursor, user-select
Cambian el cursor al pasar por encima y si el texto puede seleccionarse.
flex / fit-content (valores de display/width)
En las prácticas, display:flex coloca elementos flexibles; width:fit-content ajusta el ancho al contenido.

6. Selectores y clases de las hojas del proyecto

Estilos.css aplica el aspecto compartido: body configura letra, espaciado y fondo; header y footer comparten franja morada; los enlaces de cabecera/pie tienen color y estado :hover; main es una tarjeta blanca; fieldset, legend, label y los selectores por tipo dan formato al formulario; .form-buttons separa sus botones; .tabla-horario y sus celdas construyen el horario; .recreo destaca la pausa; details, summary, details details y ul.sublista estilizan los desplegables del índice.

Las hojas de las prácticas usan además selectores de elemento (body, h1, div, pre, hr, th, td), clases reutilizables (.parrafo, .resaltado, .subrayado, .menu-horizontal, .tabla-1, .bloque-gris, entre otras) e identificadores (#parrafo1, #parrafo2, #parrafo3). Las clases se repiten en varios elementos; cada id debe ser único dentro de una página. Las reglas de tablas, menús, párrafos, fondos e identificadores sirven para demostrar cada selector y propiedad en el ejercicio correspondiente.

La calculadora se enlaza a PrimerScripts.js: escribir() añade una tecla a la pantalla, borrar() la reinicia, e igual() está declarada pero todavía no realiza el cálculo. Los números numero1 a numero10 declarados en ese archivo no intervienen en esas funciones.
